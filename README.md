## ⚡ What is Rivyn?

Rivyn turns multi-gigabyte raw log floods into resolved incidents in seconds:
- **88% to 99.9% Alert Noise Reduction** via single-pass Drain3 template mining and topological correlation.
- **Columnar Binary Engine (Apache Parquet)**: 60% to 89.3% storage reduction with zero-copy SIMD scans.
- **Multi-Tier AI Anomaly Detection**: Statistical template rarity + Isolation Forest outlier ranking.
- **Grounded AI Copilot**: Exact line and timestamp citations (`[Line <id> @ <timestamp>]`) eliminating hallucinations.
